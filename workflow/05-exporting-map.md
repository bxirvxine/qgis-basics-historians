**Exporting the map**

This section explains how to create a print layout containing the completed map, and then to export the map as a PDF or an image file. 

1) Create a print layout

A print layout allows you to arrange the map and supporting elements, such as the title, legend and scale bar, before producing the final file. Once the map is complete, go to Project → New Print Layout. Give the layout a descriptive name and click OK. The print layout will open in a new window.

2) Add the map

In the Print Layout window, select Add Item → Add Map and draw a rectangle on the page where the map should appear.

The map will be added to the layout from the current QGIS map view. Adjust the size and position of the map by right-clicking on the map and using the Item properties panel.

3) Add map elements

Use Add Item in the Print Layout toolbar to add elements such as a title, legend and a scale bar. Check that all labels and map features are clearly visible.

4) Adjustments to the map

If you make changes to the map in the main QGIS workspace after adding it to the print layout, use the Refresh button to display those changes. This is also required after updating the CSV data.

5) Export the map

Once you have finished, export the map from the Layout menu, selecting Export as PDF or Export as image. Save the map within the project folder.

Your map is now ready to use outside QGIS.
